# The SEBD Grand Tour: provenance and evidence for an AI result

Companion page to the SEBD 2026 closing keynote, "Towards Explainable & Trustworthy AI:
Database Provenance meets Computational Argumentation" (Bertram Ludäscher, UIUC).

Live page: https://idaks.github.io/sebd-grand-tour/

`index.html` is the page; `evidence/` holds both AI toolchains' artifact bundles and the
solver-free optimality certificate; `assets/` holds the figures and their Graphviz sources.
Changes to the evidence after it was first hashed are logged in
`evidence/Claude-artifacts/CORRECTIONS.org`; changes to the page are in this repo's history.
